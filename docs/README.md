# GymTracker — веб-версия (GitHub Pages)

Личный трекер тренировок по YouTube-плейлистам. Работает как обычная веб-страница,
но добавляется на рабочий стол iPhone как отдельная иконка (через Safari "На экран «Домой»")
и открывается на весь экран, без адресной строки.

Прогресс (пройденные тренировки, позиция воспроизведения) хранится локально в браузере
(`localStorage`) на устройстве — без аккаунта, без сервера.

## 1. Включить GitHub Pages

1. На github.com откройте репозиторий → **Settings → Pages**.
2. В разделе **Source** выберите ветку (например, `main` после мержа этой ветки, либо текущую
   ветку, если Pages настраивается сразу на ней) и папку **`/docs`**.
3. Нажмите **Save**. Через ~1 минуту сайт будет доступен по адресу вида
   `https://<ваш-логин>.github.io/<репозиторий>/`.
4. После каждого нового `git push` сайт пересобирается автоматически (тоже ~1 минуту).

## 2. Получить ключ YouTube Data API v3

1. Откройте [Google Cloud Console](https://console.cloud.google.com/).
2. Выберите или создайте проект.
3. **APIs & Services → Library** → найдите **YouTube Data API v3** → **Enable**.
4. **APIs & Services → Credentials → Create Credentials → API key**.
5. **Важно** (в отличие от нативного приложения, этот ключ лежит в открытом файле на
   публичном сайте): ограничьте ключ, чтобы им нельзя было воспользоваться с других сайтов —
   в настройках ключа выберите **Application restrictions → HTTP referrers** и добавьте
   `https://<ваш-логин>.github.io/<репозиторий>/*`, а также **API restrictions → YouTube Data
   API v3** (только этот API).

## 3. Вписать ключ в проект

Откройте `docs/js/config.js` (можно прямо на github.com через встроенный редактор, либо
локально), замените `PASTE_YOUR_YOUTUBE_DATA_API_KEY_HERE` на свой ключ и запушьте изменение.

## 4. Добавить на рабочий стол iPhone

1. Откройте адрес сайта из шага 1 в **Safari** на iPhone.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Выберите **«На экран «Домой»»**.
4. На рабочем столе появится иконка GymTracker — открывается на весь экран, как обычное
   приложение.

## 5. Проверка

1. Откройте приложение → «+» → вставьте ссылку на YouTube-плейлист → «Добавить».
2. Должны появиться пронумерованные кружки по числу видео в плейлисте.
3. Откройте любую тренировку — видео должно проигрываться прямо в приложении.
4. Нажмите кнопку-галочку — кружок в списке должен закраситься.
5. Выйдите из тренировки на середине видео, откройте её снова — воспроизведение должно
   продолжиться примерно с того же места.

## Известные ограничения

- Прогресс хранится в браузере конкретного устройства (`localStorage`). Если очистить данные
  Safari или открыть сайт на другом устройстве — прогресс не перенесётся.
- API-ключ виден в исходном коде страницы всем, кто откроет ссылку на сайт — ограничение по
  HTTP referrer (шаг 2) снижает риск, но не убирает его полностью. Для личного использования
  этого достаточно.
- Удалённые/приватные видео в плейлисте всё равно попадают в список тренировок (YouTube отдаёт
  их под названием "Deleted video"/"Private video"), просто не воспроизводятся.
